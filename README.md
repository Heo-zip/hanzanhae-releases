# 한잔해 배포 파일

물을 마시며 바탕화면 화분을 키우는 macOS 앱 **한잔해**의 설치 파일을 올리는 저장소입니다.

## 내려받기

- [최신 버전 DMG (Apple Silicon Mac)](https://github.com/Heo-zip/hanzanhae-releases/releases/latest/download/hanzanhae-mac-arm64.dmg)
- [모든 버전](https://github.com/Heo-zip/hanzanhae-releases/releases)

DMG를 열고 한잔해를 응용 프로그램 폴더로 옮긴 뒤 실행합니다. 설치한 뒤에는 앱 메뉴에서 새 버전을 확인할 수 있습니다.

이 저장소에는 소스 코드가 없고, 릴리스는 자동으로 올라갑니다.
